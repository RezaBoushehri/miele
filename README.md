# miele — بهینه‌ساز برش ورق و خروجی LC4 برای اره‌ی HOMAG SAWTEQ S-200

برنامه‌ی دسکتاپ ویندوزی که لیست قطعه‌ها (طول، عرض، تعداد) و ابعاد قالب چوب را می‌گیرد، قطعه‌ها
را روی ورق می‌چیند، پیش‌نمایش الگوی برش را نشان می‌دهد و پس از تأیید، فایل `LC4` + `prv` را در
پوشه‌ی Runs دستگاه (`D:\machine1\prod_data\Cadv51\data\Runs`) می‌نویسد.

برنامه فقط وقتی **فلش مجوز** وصل باشد اجرا می‌شود (قفل سخت‌افزاری با امضای دیجیتال).

## امکانات

- ورود جدول قطعات به‌صورت **دستی** یا **بارگذاری از CSV / Excel (xlsx)** — با پشتیبانی از ارقام فارسی.
- چیدمان گیوتینی ۳ تا ۴ مرحله‌ای (نوار ← ستون ← برش مجدد ← کوتاه‌کردن) با رعایت ضخامت تیغ،
  دورریز لبه‌ها و جهت الیاف (قطعه‌هایی که نباید بچرخند).
- **پیش‌نمایش گرافیکی** هر الگو با ابعاد و نام قطعه، و گزارش راندمان.
- خروجی **عیناً هم‌فرمتِ** فایل‌های خودِ دستگاه: فرمت LC4/PRV از روی ۱۵۶ نمونه مهندسی معکوس شده
  و هر ۱۵۶ فایل بایت‌به‌بایت بازتولید می‌شوند. شرح فرمت: [docs/LC4_FORMAT.md](docs/LC4_FORMAT.md).
- قفل فلش با Ed25519 + ابزار صدور مجوز جداگانه: [docs/SECURITY.md](docs/SECURITY.md).

## اجزای تحویلی

| فایل | توضیح |
|---|---|
| `miele.exe` | برنامه‌ی گرافیکی اصلی (ویندوز، بدون پنجره‌ی کنسول) |
| `miele.exe.manifest` | کنار exe قرار می‌گیرد؛ کنترل‌های مدرن و DPI |
| `keygen.exe` | ابزار مخصوص شما برای ساخت کلید و صدور مجوز فلش |

## راه‌اندازی اولیه (یک‌بار، پیش از تحویل)

```bat
keygen.exe init                     :: ساخت کلید؛ کلید عمومی داخل برنامه جاسازی می‌شود
build.ps1                           :: دوباره build تا کلید در miele.exe بنشیند
```
سپس برای هر فلش:
```bat
keygen.exe issue -drive E: -name "نام مشتری" -days 365
```
جزئیات کامل در [docs/SECURITY.md](docs/SECURITY.md).

## ساخت از کد

بدون CGO و بدون mingw؛ از هر سیستمی قابل cross-compile است:

```bash
./build.sh            # لینوکس/مک → dist/miele.exe و dist/keygen.exe
./build.sh garble     # نسخه‌ی درهم‌سازی‌شده (مقاوم‌تر)
# یا روی ویندوز:
powershell -File build.ps1
```

## ساختار پروژه

```
cmd/miele      برنامه‌ی گرافیکی (walk، فقط ویندوز)
cmd/mielecli   موتور خط‌فرمان (برای تست/اتوماسیون؛ همان هسته)
cmd/keygen     ابزار کلید و مجوز
internal/lc4   خواندن/نوشتن فرمت LC4 و PRV  (۱۵۶ نمونه بایت‌به‌بایت)
internal/optimize  بهینه‌ساز چیدمان و ساخت درخت برش
internal/draw  رندر تصویری الگوها
internal/partsio   بارگذاری CSV و XLSX
internal/license   قفل فلش (Ed25519 + شناسه‌ی سخت‌افزاری)
internal/app   هسته‌ی مشترک GUI و CLI
lc4/ (پایتون)  پیاده‌سازی مرجع و اعتبارسنج فرمت (برای توسعه؛ جزو خروجی نیست)
```

## تست

```bash
go test ./...                 # شامل بازتولید بایت‌به‌بایت هر ۱۵۶ نمونه و بررسی هندسی خروجی
python3 -m unittest tests.test_lc4   # اعتبارسنج مرجع پایتون
```

## نکته‌ی مهم

هنوز روی خود دستگاه تست نشده. حتماً یک خروجی نمونه را در پوشه‌ی Runs کپی کنید و باز شدنش در
CADmatic را تأیید کنید. درباره‌ی حدود مقاوم‌سازی در برابر کرک، بخش «صداقت» در
[docs/SECURITY.md](docs/SECURITY.md) را بخوانید.
